## 一、现在的论文能主张什么、不能主张什么

### ✅ 站得住（强，且过了多重比较校正）

1. **`attn−final` 是 8/8 全模型唯一存活的效应**，BH 校正后 q<0.001（8 模型 × 4 edge = 32 个检验）。
   这是全文最硬的一条，也是唯一"跨三家族 + base/instruct 全覆盖"的定量主张。
2. **深度可解码性中部最高、向输出衰减**：逐层曲线在 8 模型上一致（如 3B：L9 峰 0.616 →
   L26 0.569 → final 0.538）。这条是描述性的、稳健的。
3. **零训练读出（logit lens）处处接近随机**（3B 0.560、8B 0.577），远低于训练探针。
4. **读出自由度不足以解释该优势**：给最终层**完全相同的读出流程**（2560 维、val 选 20 单元、
   逐块标准化拼接）后，`attn − 选20块` 仍 **8/8 显著**（+0.043~+0.128）。
5. **prompt 鲁棒**：3 模板 × 2 模型，两个 edge **6/6 全部同号**。
6. **样本量的教训本身是有价值的方法学发现**：500q（373 test 行）对 +0.05 量级效应无功效，
   跨家族系统性假阴性 —— 这解释了旧版"attn 在 Mistral 上弱"的错误，也正当化了统一用 1500q。

### ⚠️ 被削弱 / 必须降级

7. **`internal_edge` 只在 base 模型存活（3/8）**，instruct 上不显著。
   → "残差流内部 > 输出表示"的**强形式不能作为通用主张**，只能作为 base 模型上的现象。
8. **"读出方式"的贡献与"读哪层"相当**：换一种读出（逐块 LR ensemble）后，
   **LLaMA-3.2-3B-Instruct 上 `attn − headmean = +0.0071 [−0.015,+0.029]` 不显著**。
   → 必须正面写，不能藏。

### ❌ 站不住（这是真正的障碍）

9. **因果章节的核心判据失效。** 旧判据（只看总体 mean P(yes)）逻辑上无效，改成按标签分组的
   `alignment_gap` + 12 随机方向零分布后：**internal 方向排不进前 5%**（分位 0.00~0.83），
   而且"internal 保持 AUC"在 3B 上与 random 完全重叠、在 Qwen 上反而崩到 0.427。
   → 唯一还能用的只剩**消融臂单调崩塌**（3B 0.814→0.452、8B 0.886→0.307、8B-Inst 0.922→0.002）。
10. **"attenuation（衰减）"这个标题词没有证据支持，且 patch 实验指向相反方向**：
    把 val 选层的**真实**中层激活移植到输出层，4 个变体里 **3 个的判别力反而低于 judge**
    （0.511<0.545、0.492<0.563、0.617<0.652）。证据更像 **misalignment（错位）**。

## 二、按 CCF-B 审稿标准逐项过一遍

| 审稿人会问 | 现状 | 判定 |
|---|---|---|
| 效应是否稳健、跨模型？ | 8 模型 / 3 家族 / base+instruct，头条效应 8/8 过 BH | ✅ 强 |
| 是否有干净对照排除"训练"贡献？ | `final−judge` 有，但 `train_edge` BH 后 0/8 存活 | ⚠️ 中 |
| 是否有干净对照排除"读出自由度"贡献？ | 有，`attn − 选20块` 8/8 存活；但 headmean 变体在小 instruct 上打平 | ⚠️ 中 |
| 是否有因果证据？ | **只有消融臂单调崩塌**；定向性判据为 null；饱和问题修正重跑中 | ❌ 弱 |
| 机制解释是否成立？ | "衰减"被 patch 实验反驳，需改写成"错位"，而错位的正面证据只有 patch 一条 | ❌ 弱 |
| 是否只在一个数据集上？ | MS MARCO + FiQA(BM25 难负例，重做中) | ⏳ 取决于 FiQA 结果 |
| 是否多重比较校正？ | 有（BH） | ✅ |
| 是否 prompt-specific？ | 3 模板 6/6 同号 | ✅ |
| 统计功效是否足够？ | 1500q / 1117 test 行；已证明 500q 不足 | ✅ |

**净判断**：**描述性/相关性那半篇是扎实的（甚至比旧版更干净），机制与因果那半篇目前是空的。**
CCF-B（如 SIGIR/CIKM/WSDM 一档）对"新发现 + 可信证据链"是买账的，但**不能接受
"标题说 A、实验支持 B"**。现在的标题词（attenuated）与 patch 证据（misalignment）方向冲突，
这是**必须解决才能投**的问题——不是加实验能糊过去的，是要重新组织论证。

## 三、要补到什么程度才够（按性价比排序）

### 必做（不做就投不出去）

1. **因果饱和修正重跑**（已排队，~1 小时）。目的不是"找回显著性"，而是让空结果**可信**：
   现在的 null 有一半是饱和假象（Qwen α=±1 就 P(yes)∈{0,1}）。
   修正后若仍无定向性 → 老实写成"在可解释强度范围内未发现超出随机方向的定向效应"，
   并把因果章节降级到消融臂。**这是把"说不清"变成"说清了没有"**。
2. **改写论证结构**：标题/摘要/结论里的 "attenuated" 改成 "decodable internally but not
   usable by the output readout"（错位），并把 patch 实验提为机制主证据。
   成本：纯写作，但**这是决定能否投的关键一步**。
3. **论文全文改成"以 attn−final 为头条、内部残差为补充"**，并删除
   "attn 在 Mistral 上弱"（已被证伪）、"internal edge 在 instruct 上强"（不成立）等表述。

### 强烈建议（决定 reviewer 打 4 分还是 6 分）

4. **FiQA BM25 结果**（进行中）。若难负例下 final 不再贴天花板、且 `attn−final` 仍显著，
   "跨数据集"这条就补实了；若 FiQA 上效应消失，**必须如实报告**——但那会显著削弱论文，
   届时要考虑换一个更合适的数据集（如 TREC-DL passage）。
5. **patch 实验扩到 8 模型**（现在 4 个），因为它是替代"衰减"叙事的**唯一正面机制证据**，
   样本量不能只有 4 个变体。
6. **path patching**（把 L9 激活喂回 L9 之后继续前向到输出）：这是真正能把
   "格式不可通约"与"信息被抑制"分开的实验。现在 patch 只替换最后一个位置的残差通道，
   我自己在 TODO 里就写了这条限制——审稿人一定会问。

### 可选（加分，不决定生死）

7. Qwen/Mistral 的因果 steering 补齐；FiQA 上加第二模型；judge 阈值校准/更强 judge。

## 五、一句话结论

**这批重跑实验让论文的"测量"部分变得可信（这是净收益：修掉了选层偏差、多重比较、
样本量假象、FiQA 标签失衡），但同时把"机制/因果"那半篇暴露成了空壳。**

所以答案是：**目前不足以支撑 CCF-B 投稿；差距不在数据量，而在因果与机制论证。**
按第三节 1–3 做完（约 2 天，其中重跑已在跑），论文会落到"结论更窄但完全立得住"的位置——
那是一个 CCF-B 可以接受的形态；若再加上 4–6（约再 2 天），则有机会到 borderline-accept 以上。
